# Gravações de tela do app

Coloque aqui gravações de tela do PeladaPro (celular, vertical, MP4, 10 a 40 s cada).
Pode subir pelo próprio site do GitHub: **Add file → Upload files**.

Sugestões (nome do arquivo → o que gravar):
- `criar-pelada.mp4` — criar uma pelada nova
- `confirmar-presenca.mp4` — jogador confirmando presença
- `sorteio-times.mp4` — sorteio dos times
- `partida-ao-vivo.mp4` — placar/partida ao vivo
- `financeiro.mp4` — tela de quem pagou e quem deve

Use dados de exemplo (sem nome/telefone real de jogadores).
O agente usa cada gravação nova uma vez em um Reels e registra em `pautas/historico.csv`.
