# Reels prontos para postar

Suba aqui os vídeos já editados: **Add file → Upload files** (no celular, abra o GitHub pelo navegador
em modo "versão para computador").

- Vertical 9:16, MP4 ou MOV, até 90 segundos e **até 25 MB** (limite do upload pelo site).
- Dê ao arquivo um nome que diga o tema, ex.: `furao-confirma-e-nao-vai.mp4`.
- Quer sugerir a legenda? Crie um `.txt` com o mesmo nome (`furao-confirma-e-nao-vai.txt`).

O agente posta um por vez (o mais antigo primeiro) no lugar do carrossel e move o vídeo para `posts/`.
